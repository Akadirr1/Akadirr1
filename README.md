#### 🚤 Autonomous USV

My main engineering focus is an autonomous unmanned surface vehicle built around a distributed ROS 2 architecture.

`ROS 2` · `Nav2` · `Python` · `Computer Vision` · `YOLO` · `ZED` · `LiDAR` · `NVIDIA Jetson` · `Raspberry Pi` · `Cube Orange+` · `ArduPilot` · `CAN Bus`
